# Дом Ульяновск — лендинг

Адаптивный одностраничный сайт компании по ремонту и отделке под ключ в Ульяновске.

## Состав
- `index.html` — структура сайта
- `styles.css` — адаптивный дизайн
- `script.js` — мобильная навигация
- `favicon.svg` — иконка сайта
- `.github/workflows/pages.yml` — автоматическая публикация GitHub Pages

## Публикация
При push в ветку `main` workflow собирает и публикует сайт на GitHub Pages. Если GitHub Pages ещё не включён для репозитория, workflow попробует включить его автоматически.

## Важно перед публичным запуском
- Изображения Unsplash — демонстрационные примеры интерьеров, не подтверждённые работы компании. Замените их фотографиями реальных объектов.
- Уточните фактический список услуг, цены, сроки, гарантии и реквизиты.
- Сейчас сайт не собирает персональные данные; основное действие — звонок по номеру +7 963 128-25-58.
- Фотографии и шрифт загружаются с внешних ресурсов.
