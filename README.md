# Дом Ульяновск — лендинг

Готовый адаптивный одностраничный сайт для компании по ремонту и отделке под ключ в Ульяновске.

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в браузере.
3. Для публикации загрузите все три файла (`index.html`, `styles.css`, `script.js`) в корень хостинга.

## Перед публикацией
- Заменить демонстрационные фотографии на реальные фото объектов компании.
- Добавить фактический перечень услуг и подтверждённые преимущества.
- Уточнить юридическое наименование/реквизиты, если они нужны на сайте.
- Добавить политику обработки персональных данных, если будет подключена форма сбора заявок.
- Сейчас на сайте используется только ссылка для звонка; данные посетителей не собираются.

Фотографии загружаются с Unsplash, шрифт — Google Fonts; для автономной работы скачайте эти ресурсы локально и обновите ссылки.
